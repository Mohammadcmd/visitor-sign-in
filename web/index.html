How to set it up
  1. Create a Google Sheet in the Shock Tech account and share it only with front desk staff.
  2. In the Sheet: Extensions → Apps Script. Paste in apps-script/Code.gs and appsscript.json.
  3. Project Settings → Script properties: add ADMIN_PIN (6 to 8 digits). You can change it from section 6 afterwards.
  4. Run setup once and allow access. It creates the tabs and a KIOSK_KEY.
  5. Deploy → New deployment → Web app, Execute as Me, access Anyone. Copy the URL ending in /exec.
  6. Android app: add the URL and key as the KIOSK_API_URL and KIOSK_KEY GitHub secrets and rebuild the app. Browser: enter them below.

6Admin PIN
