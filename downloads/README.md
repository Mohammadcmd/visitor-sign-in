# Downloads

`shocktech-visitor-kiosk-demo.apk` is an **earlier** build of the Android app, from when it was made for Shock Tech only, in demo mode:
- It isn't connected to a Google Sheet, so nothing is saved anywhere but the tablet.
- The admin PIN is `123456`.
- It has no setup wizard or screening questions.

For the current app, download the **visitor-sign-in** APK from the latest run of **Actions → Build Android app**, or build it as described in [android/README.md](../android/README.md).
