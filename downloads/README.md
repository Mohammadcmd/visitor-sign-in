# Downloads

`shocktech-visitor-kiosk-demo.apk` is the Android app in **demo mode**:
- It isn't connected to a Google Sheet, so nothing is saved anywhere but the tablet.
- The admin PIN is `123456`.
- Use it to try the kiosk on a tablet.

For the real, connected app, build it with your Sheet's details as described in [android/README.md](../android/README.md).
